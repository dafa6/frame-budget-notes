Second Unit Notes

On the parts of a generative video prompt that are direction, not specification.

About these notes

Second Unit Notes is about the half of a generative video prompt that is direction rather than specification — camera behaviour, performance, physics, structure, and the choices that decide whether a technically correct clip is also worth watching.

The distinction it is built on

A prompt has two kinds of content in it, and they fail in different ways.

Specification is what the model will accept: durations, resolutions, file caps, field order, character limits. Getting it wrong produces an error, or a silent fallback, and the fix is to read the documentation.

Direction is what the model will do with what it accepts. Getting it wrong produces a clip where nothing is broken and nothing happens — a moving photograph. There is no error message for this, and no amount of additional description fixes it, because the missing thing is usually structural.

Almost everything written about prompting covers the first kind. These notes are about the second.

The recurring finding

Most of these pieces end up at the same place from different directions: the model supplies the defaults, and your words should be spent on whatever contradicts them.

A genre label already specifies character design. A scene description already specifies lighting. What is never in the prior is a camera that reacts to events, a subject that refuses to move, a physical rule that changes halfway through, or a last shot that means something different from the first. Those need words, and they need more words than they seem to, because they are competing with everything the model has seen.
